# Word Popper 🫧

Press the bubble, pop the letter dice, and chain touching letters into words before the clock runs out.
No ads. No accounts. Works offline.

## Install on Android
1. Download **WordPopper.apk** from the [latest release](../../releases/latest).
2. Open it. If Android asks, allow your browser or Files app to **install unknown apps**.
3. Tap **Install**, then open Word Popper.
